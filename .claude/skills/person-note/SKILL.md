# Person Note (PRIVATE)

Frame everything around **enablement** - how to help this person do their best work - not leverage.

Maintain `people/profiles/<name>.md` with:
- **Role & strengths:**
- **What energizes them / ikigai signals:** what work makes them come alive
- **Communication style:** how they like to receive feedback, async vs live, direct vs soft
- **What unblocks them:** how to set up tasks for their success
- **Watch-outs:** stress signals, over/under-commitment patterns
- **Recent context:** rolling notes from 1:1s, DSUs, transcripts

Base observations on actual evidence (transcripts, interactions). Keep speculative reads in `people/hypotheses.md` until confirmed. This folder is never shared.
