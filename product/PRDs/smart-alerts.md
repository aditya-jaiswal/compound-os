# PRD - Smart Alerts (demo)
**Problem:** users learn about metric changes too late. **Goal:** alert-to-action under 5 minutes.
**Scope (v1):** threshold alerts + anomaly detection on any dashboard metric; config UI; email + in-app delivery.
**Non-goals (v1):** Slack/PagerDuty routing (Later), fleet-level (Next).
**Success metrics:** % of alerts acted on; median alert-to-action time; teams with >=1 active alert.
**Owners:** Sam Chen (backend), Priya Nair (UI), Robin Park (anomaly model).
