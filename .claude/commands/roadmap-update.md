# /roadmap-update  (keep the roadmap living)

Update `product/roadmap/roadmap.md` from new signals. Input: new customer feedback, a decision, a competitive move, or a shipped item.
1. Read the current roadmap + `gtm-feedback-themes.md` + the new signal.
2. Place/reprioritize items across Now / Next / Later; a theme confirmed by more accounts moves up. Cite the signal (account / FB-id / competitive).
3. Move shipped items to "Recently shipped."
4. For items entering NOW, offer `/day-plan` + proposed tickets. Capture rationale.
Use the `product-management:roadmap-update` skill for structure if helpful.
