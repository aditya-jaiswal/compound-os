# /eod-capture

End-of-day capture - this is what makes the OS compound. Review what I worked on today and:

1. For each domain touched, extract new insights into its `hypotheses.md` (or `knowledge.md` for plain facts).
2. Check whether any existing hypothesis was confirmed today; if it hits 5+ confirmations, **promote** it to `rules.md`.
3. If any rule was contradicted, **demote** it back to `hypotheses.md`.
4. Update relevant `INDEX.md` files and `feature-index.yaml` if artifacts were added.
5. Apply auto-shard rules if any file/folder crossed threshold.
6. Save a short log to `daily/eod/YYYY-MM-DD.md`.

Do NOT edit the root `CLAUDE.md`.
