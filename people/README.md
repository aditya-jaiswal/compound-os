# people/ - PRIVATE, per-user, never committed

This domain holds a manager's private notes on teammates (1:1s, growth, motivation).
It is intentionally **empty in the public template** and **gitignored**, because private
notes about real people never belong in a shared repo.

When you run your own Compound OS, your `people/` files live here locally and stay on
your machine. The structure is shown; the content is yours alone.
